# Home Budget System

## Project Description
Home Budget System is a Python-based project used to manage household income and expenses.

## Technologies Used
- Python
- HTML
- CSS
- SQL Database

## Project Files
- `app.py` – Main Python application
- `database.sql` – Database queries
- `static/` – CSS and design files
- `templates/` – HTML pages

## Objective
The main objective of this project is to help users manage their home budget and track expenses.

## Installation
1. Download or clone this repository.
2. Install the required Python packages.
3. Configure the database.
4. Run the Python application.
